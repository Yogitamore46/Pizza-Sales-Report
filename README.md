# 🍕 Pizza Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing pizza sales data and developing an interactive dashboard using Microsoft Power BI. The dashboard provides insights into sales performance, customer ordering trends, popular pizza categories, and revenue generation.

## Project Objectives
- Analyze total revenue and total orders.
- Identify best-selling and worst-selling pizzas.
- Understand daily and monthly sales trends.
- Analyze pizza sales by category and size.
- Identify customer purchasing patterns.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel
- CSV Dataset

## Key Dashboard Visualizations
- KPI Cards
- Stacked Column Chart
- Area Chart
- Donut Chart
- Sales Performance Analysis

## Project Outcome
The dashboard helps understand business performance, identify sales trends, and make data-driven business decisions.
